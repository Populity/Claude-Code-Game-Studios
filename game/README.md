# Reels Wars: Meme Defense (прототип v0.1)

3D tower defense в браузере (Three.js, без сборки). Волны солдат, спринтеров, танков, магов и боссов; защищаешься героями-пародиями на вирусные тренды Reels.

## Запуск
```
cd game && npx serve .      # или: python3 -m http.server
```
Открыть http://localhost:3000 (нужен локальный сервер — ES-модули не грузятся с file://).

## Управление
1–5 выбрать героя · ЛКМ поставить/выбрать · Q «Вирусный момент» · Пробел — волна раньше · F — скорость · ПКМ/колесо — камера · Esc — пауза

## Что есть
- Меню, выбор уровня, ползунок сложности 1–10 (10 = ХАРДКОР), экран героев
- 3 уровня (8/9/10 волн), звёзды и разблокировка (localStorage)
- 5 анимированных героев, прокачка до 3 ур., продажа, аура-бафф от Кота DJ
- Комбо-множитель, ульта, щиты магов, броня танков, поджог, оглушение
- Bloom, тени, частицы, тряска камеры, процедурный звук и бит

Все баланс-значения — `src/data.js`. Смоук-тест: `node qa-smoke.mjs . ../production/qa/evidence`.
