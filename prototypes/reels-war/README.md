# Прототип: Война рилсами

**Гипотеза:** битвы двух Reels одной темы («царь горы») интереснее и честнее лайков,
и правило «10 квалификационных битв / ≥7 поражений = выбывание / >70% побед = Царь горы»
даёт понятный и азартный рейтинг.

**Статус:** in-progress

## Как запустить
Откройте `index.html` в браузере (лучше в мобильном режиме DevTools). Сервер не нужен.
Вкладки: **Битва** (два рилса, «Оба сразу» или «По очереди»; при «по очереди» голос открывается
только после просмотра обоих), **Мой Reels** (вставить ссылку `instagram.com/reel/...` и тему),
**Рейтинг**. Реальные ссылки показываются через официальный embed Instagram, демо-рилсы — карточками.
Данные хранятся в localStorage.

## Ограничения Instagram
- Видео не скачиваем и не храним — только официальный embed/oEmbed (правила Meta).
- Нет API «случайный чужой рилс по теме» → соперники из нашего пула.
