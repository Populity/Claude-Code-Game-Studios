# Прототип: VSV (Video vs Video)

**Гипотеза:** битвы двух клипов одной темы («царь горы») интереснее и честнее лайков,
и правило «10 квалификационных битв / ≥7 поражений = выбывание / >70% побед = Царь горы»
даёт понятный и азартный рейтинг.

**Статус:** in-progress

## Как запустить
Откройте `index.html` в браузере на телефоне или в мобильном режиме DevTools. Сервер не нужен.
Для записи с камеры нужен `https://` или `localhost` (например, `npx serve prototypes/vsv`).

## Что есть в v2 (дизайн-прототип на утверждение)
- **Онбординг:** заставка → выбор языка RU/EN → 2 экрана правил → «Войти через Instagram» (макет,
  без ввода пароля) → **экран согласия** (профиль обязателен; публикации/подписи, уведомления,
  рекомендации — переключатели) → «анализ Instagram» → выбор топиков (минимум 3).
- **Лента битв** с вертикальным свайпом: вертикальный свайп, «сторис» с топиками сверху («Для вас» = ваши топики),
  два рилса рядом с анимацией VS, режим «Оба / По очереди» (свайп или тап между A и B,
  голос открывается после просмотра обоих), голос кнопкой или **двойным тапом** (сердце + частицы),
  «Победа! +N рейтинг», автопереход к следующей битве.
- **Царь горы / Провал проверки:** полноэкранные анимации (корона + конфетти / разбитое сердце).
- **Поиск:** плитки тем в стиле Explore, поиск по темам.
- **Рейтинг:** пьедестал с анимацией, фильтр по темам.
- **Создание (+):** запись с камеры (до 30 с, смена камеры, кольцо прогресса), выбор из галереи,
  ссылка на видео в Instagram. Тема подсказывается по подписи и вашим топикам.
  **Проверка на повторы:** код рилса из ссылки + SHA-256 файла.
- **Профиль:** сетка ваших рилсов со статусом и 10 точками квалификации, настройки: язык,
  уменьшение анимаций, доступ к данным, мои топики, демо-прогон 10 битв, выход с отзывом доступа.
- Анимации: пружинные кривые, переходы экранов, шиммер-скелетоны, вибро-отклик, `prefers-reduced-motion`
  через настройку.

Скриншоты: `production/qa/evidence/vsv-*.png`.

## v3 — бренд и права (2026-10-05)
Переименовано в **VSV**: «Reels» — товарный знак Instagram. Своя палитра (лайм → мята → циан),
свой логотип, голос — молния вместо сердца, темы — скруглённые квадраты вместо кружков,
кнопка входа без глифа Instagram. Добавлены: галочка прав для своих видео, пометка
«видео остаётся в Instagram» для ссылок, «⋯ → Пожаловаться / Скрыть автора», ссылка на условия.
Подробно: `design/legal/brand-and-ip-compliance.md`.

## Принятые решения (ответы пользователя)
| Вопрос | Решение |
|---|---|
| Платформа | Мобильное приложение (React Native / Expo) |
| Источник соперников | Только наш пул, подбор по теме |
| Дизайн | Полный Instagram-подобный интерфейс, AAA-анимации, RU/EN — **до продолжения кода** |
| Топики | Как в Instagram; подбор по топикам пользователя после входа и согласия |
| Кто может заливать | Любой пользователь: свои видео (с подтверждением прав) или ссылки на публичные видео в Instagram |
| Повторы | Проверка по shortcode рилса: уже постился → отклоняется (в MVP — уникальный индекс в БД) |
| Первый шаг | Этот кликабельный прототип |

## Ограничения Instagram
- Видео не скачиваем и не храним — только официальный embed/oEmbed (правила Meta).
- Нет API «случайный чужой рилс по теме» → соперники из нашего пула.
